# Примеры запросов к amoCRM ROP MCP

Модель должна выбирать бизнес-tools, а не сырые методы API. Ниже — типичные формулировки руководителя отдела продаж и ожидаемые инструменты.

1. **Как дела у отдела сегодня?**  
   `sales_overview` без дат (текущий день).

2. **Дай краткую сводку по отделу за неделю.**  
   `sales_overview` с `date_from` / `date_to` за последние 7 дней.

3. **Сколько у нас активных сделок?**  
   `sales_overview` или `pipeline_summary` — поле `active_leads` / `total_active`.

4. **Где сейчас больше всего денег в воронке?**  
   `pipeline_summary` — смотреть `leads_value` по статусам и `total_value_active`.

5. **Покажи сделки без движения больше 2 дней.**  
   `find_stale_leads` с `days_without_activity=2`.

6. **Покажи только зависшие сделки дороже 500 000 рублей.**  
   `find_stale_leads` с `min_price=500000`.

7. **Какие крупные сделки сейчас зависли?**  
   `find_stale_leads` с повышенным `min_price`.

8. **У кого больше всего просроченных задач?**  
   `find_overdue_tasks` — блок `by_manager`.

9. **Какие сделки у Петрова без следующего действия?**  
   Сначала `sales_overview` или `search_leads`, чтобы узнать `manager_id`, затем `find_leads_without_tasks` с этим id.

10. **У каких менеджеров больше всего сделок без задачи?**  
    `find_leads_without_tasks` без фильтра, сгруппировать ответ по `manager`.

11. **Сравни Петрова и Иванова за август.**  
    Найти два `manager_id`, затем `compare_managers` с периодом августа. Не ставить ярлыки «лучше/хуже».

12. **Сколько Петров закрыл за месяц?**  
    `manager_performance` — `won_leads` и `won_revenue`.

13. **Какая выручка у Иванова?**  
    `manager_performance` — `won_revenue`, `average_won_check`.

14. **Покажи историю сделки 123456.**  
    `lead_history` с `lead_id=123456`.

15. **Когда последний раз происходило действие по сделке 123456?**  
    `lead_history` — последний элемент `timeline`, либо `find_stale_leads` / `search_leads` + история.

16. **На каком этапе находится сделка 123456?**  
    `search_leads` с `lead_id=123456` или `lead_history.current_state`.

17. **Найди сделку Иван Иванов.**  
    `search_leads` с `query="Иван Иванов"`.

18. **Поставь Иванову задачу позвонить завтра в 12:00.**  
    Найти менеджера и сделку (`search_leads`), затем `create_task` с `complete_till` на завтра 12:00.

19. **Добавь в сделку 123456 комментарий «Клиент ждёт КП».**  
    `add_note` с `lead_id=123456`.

20. **Переведи сделку 123456 в этап «КП отправлено».**  
    `pipeline_summary`, найти `status_id` по имени, затем `move_lead`.

21. **Сколько новых сделок пришло сегодня?**  
    `sales_overview` — `new_leads`.

22. **Какая конверсия у менеджера за месяц?**  
    `manager_performance` — `conversion_new_to_won` и обязательно `calculation_notes` (это не историческая конверсия этапов).

23. **Покажи просрочку только по одной воронке.**  
    `find_overdue_tasks` с `pipeline_id`.

24. **Что случилось со сделкой после смены ответственного?**  
    `lead_history` — события `entity_responsible_changed`.

Дополнительно: не путать активность в CRM (задачи, заметки, переходы) с результатом (выручка, закрытия, конверсия). MCP возвращает данные, выводы делает руководитель.
